# Migración a Flutter

El cliente móvil utiliza Flutter y Dart. Las pantallas, la navegación, los recursos de marca y las integraciones disponibles están en este repositorio. El administrador es una aplicación web independiente en BioJaverianaPUJ/adminWeb.

La estructura Android/iOS conserva como base el proyecto del equipo. El identificador Android se mantiene para permitir actualizar las instalaciones existentes; el nombre visible es BioJaveriana.

Consulta README.md para ejecutar y compilar, y docs/INTEGRACION_SRS_V03.md para distinguir los servicios conectados de los requisitos pendientes. La validación de iOS y la firma de distribución requieren sus entornos correspondientes.
